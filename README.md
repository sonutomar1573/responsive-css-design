# Section 2 — Responsive CSS Design

A responsive landing page demo using semantic HTML, CSS Grid, Flexbox, responsive breakpoints, design variables, and a mobile navigation toggle.

## Run
Open `index.html` in a browser.

## Files
- `index.html`: semantic page structure
- `styles.css`: responsive styling and layout
- `script.js`: mobile navigation toggle

Customize the branding, copy, colors and email address before submitting.
